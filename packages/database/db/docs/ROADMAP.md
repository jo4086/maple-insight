# Database Roadmap

이 문서는 [`REQ001`](./REQUIREMENTS/weapon-types-requirements.md)의 Phase 상태를 소유한다. 작성된 코드와 정적 검증은 선행 작업이며 아래 Phase의 완료를 뜻하지 않는다.

| Phase | 목표 | 의존성 | 상태 |
| --- | --- | --- | --- |
| `REQ001-P01` | 설계 정합성 검토와 승인 | [`REQ001-01`](./SPEC/weapon-types.md) | 진행 중: 설계 승인 전 |
| `REQ001-P02` | 연결, 아이템별 대체 조건, 회귀 테스트와 필요한 migration 파일 작성 | `REQ001-P01` 승인 | 대기 |
| `REQ001-P03` | 별도 승인 후 migration 적용과 실제 DB 제약 검증 | `REQ001-P02` 검증 | 대기 |
| `REQ001-P04` | 사용자 seed 데이터 검증, 별도 승인 후 실행과 재실행 검증 | `REQ001-P03`, 사용자 최종 데이터 | 대기 |
| `REQ001-P05` | 소비자 경로와 기존 정적 계산 호환성 확인 및 최종 검증 | `REQ001-P02`~`REQ001-P04` | 대기 |

## Phase 경계

### REQ001-P01

전역 타입과 버전별 아이템의 연결, `NULL`과 아이템별 대체 조건 표현, 팔라딘 정적 예외 호환성, 데이터 소유권을 결정한다. 상세 산출물과 종료 조건은 [`GOAL/weapon-types.md`](./GOAL/weapon-types.md)에 있다.

### REQ001-P02

승인된 설계만 구현한다. 필요한 migration 파일 작성은 포함하지만 실제 DB 적용은 포함하지 않는다.

### REQ001-P03

Migration 적용 승인을 별도로 확인한 뒤 대상 DB에 적용하고 제약과 기존 데이터 호환성을 검증한다. Seed 실행 승인을 대신하지 않는다.

### REQ001-P04

사용자 제공 최종 seed 데이터를 검증한다. Seed 실행 승인을 별도로 확인한 뒤 실제 DB에서 최초 실행과 재실행을 검증한다. 준비된 주무기 35종은 사용자 제공 최종 데이터가 아니다.

### REQ001-P05

DB 소비자 경로와 기존 정적 계산의 호환성을 검증한다. 팔라딘 예외 해결 전 정적 계산 경로를 제거하지 않는다.

사용자 최종 seed 데이터가 지연되면 `REQ001-P04`와 `REQ001-P05`의 데이터 종속 검증은 대기한다. 각 Phase는 [`REVIEW.md`](./REVIEW.md)에 종료 조건의 검증 근거가 기록된 뒤에만 완료로 변경한다.
