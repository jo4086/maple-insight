## 평가 지침서

**필수사항**:
`generator`와 스프린터 계약을 수행.

**example**:

    이번에 만들건 무엇인지: [기능명]
    완료 기준: [체크리스트]
    기능명.md의 최상단에 기록

### 평가 기준

| 번호 | 평가기준                                               | 중요도 |
| ---- | ------------------------------------------------------ | :----: |
| 1    | 서버 성능 및 최적화(요청 처리 속도, 비동기 처리, 캐싱) |  ★★★   |
| 2    | 코드품질(가독성, 유지보수 용이성, 코드 재활용)         |  ★★★   |
| 3    | 기능성                                                 |  ★★☆   |
| 4    | 완성도                                                 |  ★☆☆   |
