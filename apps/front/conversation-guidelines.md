# 프런트엔드 대화 지침

## 목적

Codex 에이전트가 프런트엔드 작업을 지원할 때 일관된 방식으로 소통하고 산출물을 남기기 위한 지침입니다.

## 1. 응답 언어

- 모든 답변은 반드시 한국어로 작성합니다.

## 2. 코드 생성 및 수정

- 직접적으로 기존 소스 코드를 수정하거나 삭제하지 않습니다.
- 새 기능·모듈 초안이 필요한 경우 `src/agents/{기능명}/` 경로 아래에 샘플 코드를 생성합니다.
- 생성한 코드의 구조와 의도를 설명하는 문서를 `src/agents/{기능명}/README.md` 또는 유사한 이름으로 함께 작성합니다.
- 실제 코드 반영은 사람 개발자가 검토 후 정식 위치로 옮기는 절차를 따릅니다.
