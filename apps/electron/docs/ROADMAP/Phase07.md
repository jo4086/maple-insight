## 12. Phase 7 - 운영 안정화

**상태: 대기**

### 목표

반복적인 데이터 관리 작업을 안정적으로 수행할 수 있도록 복구, 이력, 성능과 배포를 보강한다.

### 범위

- 작업 이력 조회
- 취소 및 재시도
- 장애 복구 시나리오
- 대용량 목록 가상화
- 패키징 및 Windows 배포
- 로그 정책과 민감 정보 검사
- 핵심 흐름 end-to-end 테스트

### 관련 요구사항

- `LOG-001` ~ `LOG-005`
- `NFR-PERF-001` ~ `NFR-PERF-003`
- `NFR-REL-001` ~ `NFR-REL-003`
- `NFR-UX-001` ~ `NFR-UX-004`
- `NFR-COMP-001` ~ `NFR-COMP-003`
- `NFR-OBS-001` ~ `NFR-OBS-003`

### 종료 조건

- [ ] 실패한 작업을 원인 수정 후 재실행할 수 있다.
- [ ] 앱 재시작 후에도 작업 결과와 상태를 확인할 수 있다.
- [ ] 대표 데이터 묶음의 end-to-end 적재가 통과한다.
- [ ] renderer와 로그에서 비밀값이 검출되지 않는다.
- [ ] Windows 패키지가 설치 및 실행된다.

## 13. 보류 기능

초기 제품 완료 이후 검토한다.

- 폴더 및 다중 파일 일괄 선택
- 몬스터, 보스, 심볼 등 추가 도메인 편집 UI
- 초기 제품 이후 추가 형식의 diff 보고서 내보내기 (`DIF-007` 선택 기능)
- 여러 관리자와 원격 협업
- 역할 기반 접근 제어
- 자동 업데이트
- 데이터 품질 통계와 Jev 평가 대시보드
