## 11. Phase 6 - 타입 및 정적 데이터 생성

**상태: 대기** · [상세 목표](../GOAL/Phase06.md) · [SPEC](../SPEC/04-publish.md#spec-phase-06) · [아키텍처](../ARCHITECTURE.md#architecture-data-flow)

### 목표

ready 버전을 기준으로 TypeScript 타입과 정적 데이터를 재현 가능하게 생성하고 검토한다.

### 범위

- generator 실행 계약
- 대상 버전과 출력 경로 표시
- 생성 순서 관리
- 실행 결과 요약
- Git diff 검토 연결
- 실패 상태 분리

### 관련 요구사항

- `GEN-001` ~ `GEN-006`
- `OWN-002`, `OWN-003`

### 종료 조건

- [ ] 같은 ready 버전에서 같은 생성 결과를 얻는다.
- [ ] DB 반영과 생성 실패를 서로 다른 상태로 표시한다.
- [ ] 생성 결과를 자동 커밋하지 않는다.
- [ ] 변경 파일과 오류를 사용자에게 요약한다.
- [ ] 패키지 빌드 순서를 지키며 전체 typecheck가 통과한다.

### 생성기 추적과 추가 종료 조건

ready 버전의 publish된 DB 데이터에서 타입·정적 데이터를 재현 가능하게 만든다.

- [ ] 대상 버전, 명령, 출력 경로와 입력 publish run을 실행 전 표시한다.
- [ ] 생성 결과의 파일 수·변경 파일·오류를 요약한다.
- [ ] Git diff 검토 전 자동 커밋하지 않는다.
- [ ] 생성 실패와 DB publish 결과를 별도 상태로 표시한다.
