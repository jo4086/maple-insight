# REQ004 — 스킬 레벨 상세와 하이퍼 필터

## 목적

스킬 목록에서 행 전체로 상세를 선택하고, 선택한 버전의 레벨별 설명과 하이퍼 스킬을 확인한다.

## 범위

- 스킬 표의 행 전체를 마우스와 키보드로 선택한다.
- 선택한 버전·스킬 ID의 `ms_skillLevel` DB 행을 조회해 레벨별 설명을 표시한다. 레벨 간 달라지는 텍스트만 강조한다.
- `−`와 `+`로 실제 존재하는 레벨 행을 이동한다. `마스터하기`는 `maxLevel`의 레벨로 이동하며, `maxLevel`을 초과하는 레벨 행도 `+`로 열람할 수 있다.
- 4차와 5차 사이에 하이퍼 필터를 둔다. `hyper === 1`만 하이퍼에 표시하고, 일반 차수 필터에서는 제외한다. 전체 필터에는 모두 표시한다.
- 5차 스킬 분류와 스킬 유형 판정은 후속 범위다.

## 검증

- [x] 행의 아이콘 셀 클릭과 키보드 선택으로 상세를 연다.
- [x] 레벨 변경, 동적 텍스트 강조, 마스터 이동 및 `maxLevel` 초과 레벨 열람을 확인한다.
- [x] 하이퍼 필터에서 `hyper === 1` 스킬만 표시한다.
- [x] 실제 DB에서 버전별 레벨 설명과 하이퍼 값을 확인한다.
- [ ] native Electron에서 레벨별 설명과 하이퍼 필터를 확인한다.

검증 기록은 [Electron REVIEW](../REVIEW.md)를 따른다. Phase 04 전체 완료 상태와는 별개다.
