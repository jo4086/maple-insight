# Electron 요구사항

Electron이 소유하는 신규 기능 요구사항을 안정적인 REQ ID로 관리한다. Phase 상태는 [ROADMAP](../ROADMAP.md)만을 기준으로 한다.

| 요구사항                                                                | 기능                         | 관련 목표                                               |
| ----------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------- |
| [`REQ001`](../../../../docs/electron/nexon-open-api-spec-monitoring.md) | 넥슨 Open API 명세 변경 감지 | 외부 제안 문서에 남아 있으며 이 목차로 이전하지 않는다. |
| [`REQ002`](./REQ002.md)                                                 | 새 직업 분류 초안 흐름       | [REQ002-Phase01](../GOAL/REQ002/Phase01.md)             |

`REQ001`은 기존 실제 문서 경로를 유지하는 역사적 외부 제안이다. Electron `REQ001`이나 Core `REQ001`을 이동·변경하지 않는다.
