# REQ003 — 스킬 이미지 로컬 연결과 직업별 추출

## 목적

전직 ID별로 추출한 PNG를 현재 스킬 목록에 표시하고, 선택한 대표 직업의 연결 전직 ID를 한 번에 추출하는 Electron 동작을 제공한다.

## 범위

- 스킬 목록의 현재 버전 직업 묶음에서 전직 ID를 결정한다. C# 추출기에 직업 관계를 별도로 하드코딩하지 않는다.
- `skills/{version}/{jobID}/{skillID}/` PNG를 Main에서 읽어 같은 데이터 버전의 스킬 목록에만 연결한다. `jobID`의 앞자리 0 차이는 파일 경로에서 정규화하되 DB 원본 문자열은 변경하지 않는다.
- 선택 직업의 `이미지 추출 및 등록` 버튼은 연결 전직 ID를 추출기에 전달하고, 완료 후 목록의 PNG 연결을 갱신한다. 여기서 등록은 로컬 PNG를 화면에 연결하는 의미다.
- 누락 아이콘과 추출 오류를 구분해 결과를 표시하고, 동시 추출 요청을 막는다. Renderer가 임의의 읽기·쓰기 파일 경로를 IPC에 전달하지 못하게 한다.

## 현재 경계

- WSL 개발 환경은 Windows .NET 추출기를 호출한다. 현재 개발용 기본 WZ 경로와 출력 루트를 사용하며 환경 변수로 재지정할 수 있다.
- 조회와 추출 경로는 선택한 데이터 버전으로 분리한다. 사용자가 기존 PNG 전부를 `1.2.419` 추출 결과로 확인해 해당 버전 디렉터리로 이전했다. 이후 출처를 확인할 수 없는 버전 미지정 PNG는 자동 이전·표시하지 않는다. WZ 원본 버전과 선택한 DB 버전의 일치 여부는 아직 판정하지 않는다.
- Windows 설치본의 환경설정 화면, 추출기 패키징과 실행 검증, PNG 바이트의 DB 백업·복구 및 전체 직업 순회는 [후속 아키텍처 제안](../../../../tools/docs/ARCHITECTURE.md#6-후속-제안--windows-경로-설정과-이미지-db-백업)의 대기 범위다.
- 현재 스킬 목록과 DB 조회는 [Phase 04 목표](../GOAL/Phase04.md)의 읽기 전용 부분 구현을 유지한다. REQ003 검증이 Phase 04 전체 완료를 뜻하지 않는다.

## 수용 기준

- [x] 기존 전직 `112` PNG가 실제 WSL Electron의 스킬 목록에 표시된다.
- [x] 히어로 버튼 실행이 현재 직업 묶음의 전직 ID 6개를 처리하고 기존 PNG를 재사용한다.
- [x] 목록 기본 아이콘, 상세 아이콘 3종 및 버튼 실행 뒤 갱신을 UI 자동 검증에서 확인한다.
- [x] 다른 데이터 버전의 같은 `jobID/skillID` PNG는 조회하거나 재사용하지 않는다.
- [ ] Windows 설치본에서 사용자 설정 경로로 추출기 실행과 이미지 표시를 검증한다.

검증 근거는 [Electron REVIEW](../REVIEW.md#req003-스킬-이미지-로컬-연결-부분-검증-2026-11-14)에 기록한다.
