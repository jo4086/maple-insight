2026-11-16 저장소 기준의 **포트폴리오 제작용 사실 자료**다. 이 문서들은 제품 명세나 단계 상태의 원본을 대체하지 않는다. 현재 상태가 바뀌면 [루트 로드맵](../../ROADMAP.md), [현재 목표](../../GOAL.md), 각 앱·패키지의 검증 기록을 다시 확인한다.

## 해석 기준

- **구현**은 관련 코드가 존재함을 뜻한다. 실제 환경에서 기능이 끝까지 작동했다는 뜻은 아니다.
- **검증 완료**는 담당 문서에 종료 근거가 있는 단계에만 사용한다.
- **부분 구현**과 **계획**은 공개 서비스의 제공 기능처럼 표현하지 않는다.
- 수치는 해당 검증 기록의 시점과 대상을 함께 적는다. 현재 운영 수치나 성능 개선률로 일반화하지 않는다.

우선 확인할 원본은 [프로젝트 소개](../../README.md), [SPEC](../../SPEC.md), [ROADMAP](../../ROADMAP.md), [GOAL](../../GOAL.md), [Electron 단계 상태](../../apps/electron/docs/GOAL/README.md), [DB 단계 상태](../../packages/database/db/docs/ROADMAP.md)다.
