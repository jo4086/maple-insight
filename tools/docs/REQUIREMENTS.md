# Skill Image Extractor — 요구사항

## 1. 대표 jobID 기반 추출

사용자는 대표 jobID를 입력하거나 Electron에서 직업을 선택하여 연결된 모든 전직 jobID의 스킬 이미지를 추출한다.

예시:

| 대표 직업 | 대표 jobID | 연결된 전직 jobID            |
| --------- | ---------- | ---------------------------- |
| 히어로    | 112        | 000, 100, 110, 111, 112, 114 |
| 팔라딘    | 122        | 000, 100, 120, 121, 122, 124 |

연결 정보는 기존 Maple Insight 프로젝트에서 관리하는 데이터를 활용한다. C# 추출기에 동일한 관계를 중복 하드코딩하지 않는다.

## 2. 이미지 저장 구조

대표 jobID별 중첩이 아닌, 전직 jobID를 최상위 폴더로 사용하는 Flat Structure를 사용한다.

```text
skills/
├── 000/
│   └── {skillID}/
│       ├── icon.png
│       ├── iconMouseOver.png
│       └── iconDisabled.png
├── 100/
│   └── {skillID}/
├── 110/
├── 111/
├── 112/
├── 114/
├── 120/
├── 121/
├── 122/
└── 124/
```

각 skillID에 대해 일반, 마우스 오버, 비활성화 아이콘을 추출한다.

## 3. 중복 및 누락 처리

- 이미 추출 완료된 전직 jobID는 재사용한다.
- 공용 전직 ID는 여러 직업이 공유한다.
- 폴더 존재 여부만으로 추출 완료를 판단하지 않는다.
- 부분 추출 및 작업 중단 시 누락된 이미지를 복구할 수 있어야 한다.
- WZ 원본에 이미지가 없는 경우와 추출 오류를 구분한다.
- UOL 참조를 해석하고 중복 스킬을 처리한다.

예시: 히어로 추출 후 팔라딘 추출 시 `000`, `100`은 재사용하고 `120`, `121`, `122`, `124`만 추가한다.

## 4. Electron 연동

스킬 데이터 탭에서 이미지가 없거나 일부 누락된 경우 **이미지 추출 및 등록** 버튼을 제공한다.

예상 동작:

1. 선택된 직업의 이미지 상태 확인
2. 연결된 전직 및 스킬 ID 결정
3. C# 추출기 실행
4. 이미지 추출 및 저장
5. 기존 프로젝트의 에셋 관리 방식에 맞춰 등록
6. 처리 결과 및 오류를 Electron UI에 반영

추출과 등록의 책임을 구분하고, 기존 데이터 관리 기능을 우선 재사용한다.

## 5. Electron 환경설정

환경설정 버튼 및 설정 화면을 추가한다.

필요한 설정:

- WZ 원본 파일 경로
- 추출 이미지 저장 경로
- 필요한 경우 C# 추출기 실행 경로

설정은 Electron 재실행 후에도 유지하며, 경로 유효성을 검증한다.

## 6. 실행 환경

### 현재: WSL 개발 환경

- WSL Ubuntu에서 Electron 실행
- Windows에 .NET 8 SDK 설치
- Windows에 WZ 원본 파일 존재
- WSL과 Windows 사이의 실행 및 경로 처리 필요

가능하면 Electron 버튼으로 자동 추출하고, 어려울 경우 CLI 실행 후 등록하는 대안을 마련한다.

### 향후: Windows 배포 환경

Windows에 설치된 Electron에서 추출기를 직접 호출하여 이미지 추출과 등록을 자동으로 수행하는 것이 목표다.

사용자가 별도의 터미널 명령을 입력하지 않는 구조를 지향한다.
